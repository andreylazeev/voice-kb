VoiceKB privacy

VoiceKB processes microphone audio and typed text on the phone. It uses the internet to download the selected cleanup model from Hugging Face and to check or download updates from GitHub Releases. You can turn on automatic update checks in settings. These requests contain no audio, typed or dictated text, or learned words. The downloaded model runs on the phone. Dictation is kept in memory for processing and insertion. A draft interrupted by a screen change is kept in memory until it is inserted or discarded. Android manages microphone permission and its personal dictionary.

Keyboard personalisation

VoiceKB can keep a small vocabulary and counts from the words and suggestions you accept. It stores them on the phone, separated by language and input mode. Password fields are excluded from learning. When an app requests input without personalisation, VoiceKB shows an incognito icon and disables learning, the personal dictionary, and emoji history. Incognito dictation interrupted by a field change is discarded. Open Keyboard → Personalisation to turn off individual features or clear the learned data.
